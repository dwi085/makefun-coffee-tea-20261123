A [make.fun](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) entry for "One Letter: Coffee or Tea". The program writes exactly one letter — **A, for coffee** — to `/output/entry.txt` and nothing else. No word, no explanation, no punctuation, no extra newline. Coffee is the bolder, more alive answer: dark, hot, unapologetic, the drink that turns a slow morning into a working one.
